A 2D canvas arcade flight game: you are a courier pilot flying a short
delivery route through a storm. Collect the glowing delivery rings, dodge
the storm cells, and land on runway 27 before the clock runs out.

## Play

Serve `game/` locally and open it in a desktop browser:

```sh
node serve.ts
# open http://localhost:8080
```

- **Arrows / WASD** — steer (climb and dive; the plane sinks gently if you let go)
- **Space** — boost (short burst, then it recharges)
- **Mouse** — hold to steer toward the pointer
- **R** — restart instantly, **M** — mute

The HUD always shows altitude, speed, heading, time, score and rings
collected; the bottom instrument panel has lit altitude, speed and heading
dials, an artificial horizon, a boost gauge and a storm lamp.

The hook is turbulence: fly close to a storm cell and the plane shudders,
steering goes mushy and the storm lamp flashes — and flying into a cell's
core ends the run. Rings add +2 seconds each; reaching the runway wins.

## Build

Pure 2D canvas, no libraries, no network requests, no external assets —
all art and sound are generated by the code itself (WebAudio bleeps for
rings, boost, thunder, landing).

```
game/
  index.html        page + canvas
  src/config.js     all tunable numbers
  src/random.js     seeded RNG (deterministic route)
  src/input.js      keyboard + mouse
  src/audio.js      synthesized WebAudio effects
  src/world.js      terrain, river, town, runway, rings, storms, flight model
  src/render.js     sky, terrain, plane, HUD, lit instruments
  src/shots.js      screenshot presets (?shot=cover|storm|landing|title)
  src/main.js       game loop + state machine
```

Hand in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`, which
copies `game/` and `screenshots/` and writes `dossier.json`.
